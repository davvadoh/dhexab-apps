ARRIVO – GITHUB PAGES

1. Ladda upp hela mappen arrivo/ till roten av GitHub-repot som publicerar dhexab.com.
2. Då finns svenska sidan på https://dhexab.com/arrivo/ och engelska på https://dhexab.com/arrivo/en/.
3. Lägg till en länk i den befintliga startsidans Arrivo-sektion: <a href="/arrivo/">Läs mer om Arrivo</a>
4. Kontrollera att produktinformation, licensmodell och funktioner stämmer före publicering.
5. Registrera sitemap i Google Search Console.
6. För analys: skapa Cloudflare Web Analytics eller Google Analytics och placera tjänstens script precis före </body> på båda index.html-filerna. Kontrollera integritetsinformation och samtyckeskrav.

OBS! Sidan innehåller ingen analytics-kod ännu eftersom en personlig mätkod från tjänsten behövs.
