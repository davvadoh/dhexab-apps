Privacy Policy for Dhex Lock

Last updated: November 11, 2026

Dhex Lock is a kiosk app for Android published by DHEX AB, Sweden.

Developer: DHEX AB (org. no. 559418-9143), Sweden
Contact: support@dhexab.com

In short

Dhex Lock does not collect any personal data. The app has no accounts, no analytics, no advertising and no cloud service. DHEX AB never receives any information from the app or from the device it runs on.

What is stored on the device

Everything the app stores stays on the device, in the app's private storage:

  • your settings (start address, allowed domains, chosen app, playlist, schedule and so on)
  • the admin PIN, if you set one, stored only as a salted hash
  • the access key for the local API
  • media files that you asked the app to download for playback.

This is removed when you clear the app's data or uninstall the app. Nothing is backed up to the cloud and nothing is transferred to a new device automatically.

Network traffic

The app only contacts the addresses you configure yourself:

  • the web page you show in web mode
  • media files from web addresses that you add to the playlist.

Those websites and servers are run by you or by third parties and have their own privacy policies. Dhex Lock adds nothing to that traffic. The built-in web view's usage statistics and Safe Browsing lookups are turned off.

Local API

The app can answer commands from other systems on your own local network, for example to turn the screen on or off or to read the device's status. The API only answers while kiosk mode is active and only to requests that carry the access key shown in the app's admin menu. The traffic is not encrypted and is intended for a network you trust. You can turn the API off in the admin menu. The app never contacts any server on its own through this function.

Camera, microphone and location

  • Motion detection (off unless you turn it on): the camera compares pictures to detect movement in front of the device. The pictures are analysed on the device, are never saved and are never sent anywhere.
  • Photo through the local API: a photo is taken and returned only when a system on your network requests it with the access key. The photo is not saved on the device and is not sent to DHEX AB or anyone else.
  • Web pages: if you allow it in the settings, the web page you show can use the camera, microphone or location. That data is then handled by that web page, not by Dhex Lock. All three settings are off unless you turn them on.

Device administration

To lock the device, the app is set as Device Owner by you. It uses this only to keep the device in kiosk mode: to lock the screen to the chosen content, start after a restart, block the ways out of the kiosk and apply the screen and volume settings you choose. The app does not read messages, contacts, files or other apps' data. When you exit kiosk mode all restrictions are removed, and you can remove Device Owner from the admin menu.

Children

Dhex Lock is a tool for businesses and other organisations and is not directed at children.

Sharing

No data is shared with anyone, because no data is collected.

Changes

If this policy changes, the new version is published on this page with a new date.

Integritetspolicy för Dhex Lock

I korthet

Dhex Lock samlar inte in några personuppgifter. Appen har inga konton, ingen analys, inga annonser och ingen molntjänst. DHEX AB får aldrig någon information från appen eller från enheten den körs på.

Vad som lagras på enheten

Allt som appen lagrar stannar på enheten, i appens privata lagring:

  • dina inställningar (startadress, tillåtna domäner, vald app, spellista, schema och så vidare)
  • admin-PIN, om du har valt en, lagrad enbart som saltad hash
  • åtkomstnyckeln för det lokala API:et
  • mediefiler som du har bett appen ladda ned för uppspelning.

Detta tas bort när du rensar appens data eller avinstallerar appen. Ingenting säkerhetskopieras till molnet och ingenting förs automatiskt över till en ny enhet.

Nätverkstrafik

Appen kontaktar bara de adresser du själv ställer in:

  • webbsidan du visar i webbläget
  • mediefiler från webbadresser som du lägger till i spellistan.

De webbplatserna och servrarna drivs av dig eller av tredje part och har egna integritetspolicyer. Dhex Lock lägger inte till något i den trafiken. Den inbyggda webbvyns användningsstatistik och Safe Browsing-uppslag är avstängda.

Lokalt API

Appen kan ta emot kommandon från andra system på ditt eget lokala nätverk, till exempel för att släcka eller tända skärmen eller läsa av enhetens status. API:et svarar bara medan kioskläget är aktivt och bara på anrop som har den åtkomstnyckel som visas i appens admin-meny. Trafiken är inte krypterad och är avsedd för ett nätverk du litar på. Du kan stänga av API:et i admin-menyn. Appen kontaktar aldrig någon server på eget initiativ genom den här funktionen.

Kamera, mikrofon och plats

  • Rörelsedetektering (av tills du slår på den): kameran jämför bilder för att upptäcka rörelse framför enheten. Bilderna analyseras på enheten, sparas aldrig och skickas aldrig någonstans.
  • Bild via det lokala API:et: en bild tas och returneras bara när ett system på ditt nätverk begär den med åtkomstnyckeln. Bilden sparas inte på enheten och skickas inte till DHEX AB eller någon annan.
  • Webbsidor: om du tillåter det i inställningarna kan webbsidan du visar använda kamera, mikrofon eller plats. De uppgifterna hanteras då av webbsidan, inte av Dhex Lock. Alla tre inställningarna är av tills du slår på dem.

Enhetsadministration

För att kunna låsa enheten gör du appen till Device Owner. Den rollen används bara för att hålla enheten i kioskläge: låsa skärmen till det valda innehållet, starta efter omstart, spärra vägarna ut ur kiosken och tillämpa de skärm- och volyminställningar du väljer. Appen läser inte meddelanden, kontakter, filer eller andra appars data. När du avslutar kioskläget tas alla spärrar bort, och du kan ta bort Device Owner från admin-menyn.

Barn

Dhex Lock är ett verktyg för företag och andra organisationer och riktar sig inte till barn.

Delning

Inga uppgifter delas med någon, eftersom inga uppgifter samlas in.

Ändringar

Om policyn ändras publiceras den nya versionen på den här sidan med nytt datum.
